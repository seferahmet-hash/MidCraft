# MidCraft (by Sefer Ahmet)

**MidCraft** is a modern, native macOS desktop application designed as a unified creative workspace integrating **Midjourney** and **Magnific AI** (`mcp.magnific.com`). Created and conceptualized by **Sefer Ahmet**, it bridges the gap between text-to-image generation and ultra-high-resolution AI detail enhancement in a seamless SwiftUI interface.

## Features
- **Native macOS UI**: Built with SwiftUI, featuring a modular split-view layout and dark-mode first design.
- **Midjourney Integration**: Direct prompt submission, aspect ratio configuration, and generation pipeline.
- **Magnific AI**: Advanced texture enhancement, creativity control sliders, and high-scale upscaling.
- **Layer-Based Workflow**: Non-destructive workspace architecture for managing AI-generated assets.

## Building from Source

1. Clone the repository:
   git clone [https://github.com/seferahmet/MidCraft.git](https://github.com/seferahmet/MidCraft.git)
   cd MidCraft

2. Build and package the app via terminal:
   swift build -c release
